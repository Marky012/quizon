================================================================================
WOOF GENERATION PROMPTS - REWRITE OF SECTION 14.2
Written after the Tala test produced three feet and two human arms.
================================================================================

WHY THIS FILE EXISTS
--------------------
The old prompts failed anatomically. Four causes, all of them structural:

  1. "She holds a magnifying glass ... in one front paw." The words "holds" and
     "in one front paw" are an instruction to draw a HAND. Every "in one front
     paw he holds X" line in the old set was asking for a grip, and a grip needs
     fingers, so the model drew arms. It also lifted a front paw off the
     baseline, and a lifted paw plus occlusion is how you get three feet.
     RULE ADOPTED HERE: no pup holds, grips, carries or pinches anything. Props
     rest on the ground, are worn on the body, or float in the air.

  2. The negative prompt in art bible 14.6 bans bird anatomy but never bans
     human anatomy. It lists feathers, beaks and talons, and not one of arms,
     hands or fingers. The exact failure you saw was un-negated.
     FIXED HERE: every block ends with its own MUST NOT CONTAIN line that bans
     arms, hands, fingers, thumbs, wrists and elbows.

  3. "Same set as seven other dogs:" is a cross-reference to a document the
     model has never seen. It wasted a fifth of the prompt and reset the
     description. It is gone. Each block now restates the full contract.

  4. The set contract was buried in a single 500-word run-on paragraph, so the
     anatomy rules arrived after the prop description and lost the weighting.
     FIXED HERE: each block is split into labelled sections and the anatomy
     lock is the second section, immediately after the subject.

  You no longer append anything. Each block between the markers is complete.

ALSO WORTH KNOWING
------------------
The old art bible palette was wrong. Section 2.1 says "EIGHT colours" and the
CSS has eight tokens, but the 14.1 master suffix and all eight pup blocks list
only SEVEN of them. Every block demanded a #1A2B4C outline that its own palette
list forbade, and Coco's block described a #00A396 coat that its own palette
list forbade. The palette line below is corrected to nine values: the eight
tokens plus deep turquoise, which src/index.css carries as
--color-turquoise-deep for Coco.

================================================================================
HOW TO USE
================================================================================
  1. Paste ONE block into your image generator. Paste one pup at a time.
  2. Save the result under the SAVE AS name given in that pup's header.
  3. Check it against MUST PASS before you accept it.
  4. Only after idle is accepted, use the STATE DELTAS at the bottom of this
     file to produce happy, hint and sleepy. Never generate the other three
     states from this prompt, or the four states drift apart.
